AI日報作成アプリ Daily

日々の業務メモからAIが日報文章を自動生成し、保存・検索・外部連携まで行えるWebアプリです。

アプリ概要

Dailyは、業務内容を簡単に入力するだけで、AIが日報形式の文章を生成するアプリです。 日報作成の時間を短縮し、振り返りや報告業務を効率化することを目的としています。

主な機能

AI日報生成

入力した業務メモをもとに、AIが自然な日報文章を生成します。

日報保存

ログインユーザーは生成した日報を保存できます。

日報検索

過去の日報を日付やキーワードで検索できます。

外部連携

Slack、Microsoft Teams、Gmailへの送信設定ができます。

使用技術

  • Python
  • HTML / CSS
  • JavaScript
  • SQLite
  • OpenAI API
  • Git / GitHub
  • PythonAnywhere

工夫した点

  • 未ログイン時はAI生成のみ利用可能にし、保存機能はログイン後に制御
  • 画面幅に応じてスマートフォンでも使いやすいレスポンシブ対応を実装
  • 外部連携設定をユーザーごとに保存できるように設計
  • 日報作成の流れが分かりやすいよう、入力・生成・保存の導線を整理
